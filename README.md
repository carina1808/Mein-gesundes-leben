# Mein gesundes Leben

Eine offline nutzbare Smartphone-App zum Dokumentieren von Ernährung, Bewegung, Schlaf, Gewicht, Bauchumfang und Wochenrückblicken.

## App

`index.html` ist die vollständige App in **einer einzigen Datei** (HTML, CSS und JavaScript). Sie benötigt keine weiteren Dateien und kann lokal im Browser geöffnet werden.

## Speicherung und Datenschutz

Die App speichert persönliche Einträge lokal im Browser. Eine zusätzliche lokale Kopie ist **kein** Schutz vor dem Löschen von Browserdaten oder einem Gerätewechsel. Erstelle regelmäßig unter **Einstellungen → Datensicherung** eine JSON-Sicherungsdatei und bewahre sie außerhalb des Browsers auf.

**Keine persönlichen JSON-Sicherungen, Gewichts- oder Tagebuchdaten auf GitHub hochladen.**

Der bisherige Speicherschlüssel `meinweg_v1_local` bleibt aus Kompatibilitätsgründen bestehen. Unterschiedliche lokale Dateipfade können trotzdem getrennte Speicherbereiche verwenden.

## GitHub-Upload am Smartphone

1. Auf GitHub ein **privates** Repository `mein-gesundes-leben` öffnen.
2. **Add file → Upload files** auswählen.
3. Die drei Dateien `index.html`, `README.md` und `CHANGELOG.md` aus diesem Ordner einzeln auswählen (ggf. nacheinander hochladen).
4. **Commit changes** wählen.

Alle Dateien gehören direkt ins Stammverzeichnis des Repositorys; es sind **keine Unterordner nötig**.
